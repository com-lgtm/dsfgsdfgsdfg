# Eclipse portfolio
Open index.html directly. The website works offline, with no dependencies or installation.
Design follows the approved dark cinematic proposal: serif lettering, a wide hero scene, copper beveled controls and three selectable project thumbnails.
The site is in English. All five portfolio images are actual user-provided Roblox screenshots. The Silent Keeper / Scarecrow is excluded.
Click a thumbnail to change the featured project. View project opens the large gallery. Arrow keys browse, Escape closes, and keyboard focus returns to the opener.
On smaller screens, the layout and selected works adapt to a single column.
The main website files are index.html, style.css, app.js and assets/.

Verification: real-browser checks passed for hero switching, project selection, previous/next, keyboard navigation, Escape, focus restoration and mobile dialogs. Viewports 390, 768, 1440 and 1920 fit without horizontal overflow. No runtime errors. Rendered design lint has zero failures; four approved design exceptions are documented in style.css.
